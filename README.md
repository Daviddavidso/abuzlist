# абузлист — каталог офферов

Статический сайт: чистый HTML, CSS и JavaScript. Без сборки, без npm, без базы данных.
Заливается на любой хостинг простым копированием файлов.

## Что где лежит

| Файл | Зачем |
|---|---|
| `data.js` | **Единственный файл, который нужно править.** Офферы, категории, лента обновлений, ссылка на телеграм. |
| `index.html` | Разметка страницы. Трогать не нужно. |
| `styles.css` | Оформление. Трогать не нужно. |
| `app.js` | Логика каталога: фильтры, поиск, сортировка, окно оффера. Трогать не нужно. |
| `fonts/` | Шрифт Onest, лежит на своём хостинге — сторонние загрузки не нужны. |
| `favicon.svg` | Иконка вкладки. |

## Как добавить оффер

1. Открой `data.js` в любом текстовом редакторе (Блокнот тоже подойдёт).
2. Найди массив `const OFFERS = [`.
3. Скопируй любой блок от `{` до `},` и вставь сразу после `const OFFERS = [`.
4. Замени значения на свои. Обязательные поля: `id`, `brand`, `title`, `category`, `payout`, `url`.
5. Сохрани файл и залей его на хостинг поверх старого.

`id` — любой уникальный набор латинских букв, повторяться не должен.

Значения полей:

- `category` — `banks`, `crypto`, `invest`, `market`, `food`, `betting`, `other`
- `difficulty` — `easy`, `medium`, `hard`
- `payout` — число рублями, без пробелов и знака ₽: `3500`
- `badge` — `'hot'` (метка «Топ»), `'new'` (метка «Новый») или `null`
- `promo` — промокод строкой или `null`, если промокода нет
- `timeISO` — `PT10M` — 10 минут, `PT1H` — час, `P1D` — день

## Как поменять ссылку у оффера

В нужном блоке замени строку:

```js
url: 'https://твоя-партнёрская-ссылка',
```

Ссылки открываются в новой вкладке с атрибутами `rel="noopener sponsored"` — так требуют
партнёрские сети и поисковики. Метка `noreferrer` намеренно не ставится: она обнуляет
атрибуцию переходов у большинства партнёрок.

## Как скрыть оффер, не удаляя его

Добавь в его блок строку:

```js
hidden: true,
```

## Как поменять телеграм, дату обновления и название

Всё в начале `data.js`, в блоке `const SITE = { ... }`. Меняется в одном месте — подставляется
в шапку, ленту, FAQ и подвал автоматически.

## Как залить на хостинг

1. Подключись к хостингу по FTP (FileZilla, Total Commander или файловый менеджер в панели хостинга).
2. Зайди в папку сайта — обычно `public_html` или `www`.
3. Скопируй туда **всё содержимое** этой папки: `index.html`, `styles.css`, `app.js`, `data.js`,
   `favicon.svg` и папку `fonts` целиком.
4. Открой домен в браузере. Если страница старая — обнови жёстко: `Ctrl + F5`.

Дальше, чтобы обновить каталог, достаточно заливать один `data.js`.

## Ссылки на категории

Каталог сам подставляет параметры в адрес — можно давать прямую ссылку на нужный раздел:

- `сайт.ру/?cat=crypto` — сразу открытые криптобиржи
- `сайт.ру/?cat=banks` — банки и карты
- `сайт.ру/?q=ozon` — сразу с поиском по слову

Удобно для постов в телеграме.

## Что заложено внутри

- Живой поиск, фильтр по категориям и 5 вариантов сортировки — без перезагрузки страницы.
- Карточка оффера с пошаговой инструкцией и условиями в модальном окне.
- Копирование промокода в один клик, с запасным способом для сайтов без HTTPS.
- Полная адаптация под телефон.
- Доступность по WCAG 2.2 AA: управление с клавиатуры, поддержка скринридеров,
  проверенные контрасты, видимый фокус, корректные заголовки и живые области.
- Ноль внешних запросов: шрифты, иконки и скрипты свои. Сайт грузится быстро и работает
  даже если сторонние CDN недоступны.
