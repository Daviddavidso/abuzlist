# финвитрина — сравнение банковских продуктов и займов

Информационный сервис сравнения: кредиты наличными, дебетовые карты и микрозаймы
в одном формате. Статический сайт — чистый HTML, CSS и JavaScript. Без сборки,
без npm, без базы данных. Заливается на любой хостинг простым копированием файлов.

## Что где лежит

| Файл | Зачем |
|---|---|
| `data.js` | **Единственный файл, который нужно править.** Продукты, категории, лента изменений, название и почта. |
| `index.html` | Разметка страницы. Трогать не нужно. |
| `styles.css` | Оформление. Трогать не нужно. |
| `app.js` | Логика: фильтры, поиск, сортировка, карточка продукта. Трогать не нужно. |
| `fonts/` | Шрифт Onest, лежит на своём хостинге — сторонние загрузки не нужны. |
| `favicon.svg` | Иконка вкладки. |

## Как добавить продукт

1. Открой `data.js` в любом текстовом редакторе.
2. Найди массив `const PRODUCTS = [`.
3. Скопируй любой блок от `{` до `},` и вставь сразу после `const PRODUCTS = [`.
4. Замени значения. Обязательные поля: `id`, `brand`, `title`, `category`, `specs`, `url`.
5. Сохрани файл и залей его на хостинг поверх старого.

`id` — любой уникальный набор латинских букв, повторяться не должен.

Значения полей:

- `category` — `credit` (кредиты наличными), `debit` (дебетовые карты), `mfo` (микрозаймы)
- `specs` — до четырёх пар `['Подпись', 'Значение']`, это то, что видно в карточке
- `sortRate` / `sortSum` / `sortTerm` — числа для сортировок «по ставке», «по сумме», «по сроку»
- `tag` — короткая метка на карточке (`'Онлайн-заявка'`) или `null`
- `note` — строка мелким шрифтом под кнопками, обычно про ПСК

## Как поменять партнёрскую ссылку

В нужном блоке замени строку:

```js
url: 'https://партнёрская-ссылка',
```

Ссылки открываются в новой вкладке с атрибутами `rel="noopener sponsored"` — так требуют
партнёрские сети и поисковики. Метка `noreferrer` намеренно не ставится: она обнуляет
атрибуцию переходов у большинства партнёрок.

## Про звёздочки в цифрах

Все значения в карточках помечены звёздочкой и по всему сайту описаны как **ориентиры для
сравнения**. Это не украшение, а защита: условия у банков и МФО меняются чаще, чем
обновляется сайт, а итоговую ставку определяет решение по конкретной заявке. Формулировки
про ориентиры есть над каталогом, в карточке продукта, в FAQ и в подвале — их лучше не убирать.

## Как скрыть продукт, не удаляя его

Добавь в его блок строку:

```js
hidden: true,
```

## Как поменять название и почту

Всё в начале `data.js`, в блоке `const SITE = { ... }`. Меняется в одном месте — подставляется
в шапку, подвал и заголовок вкладки автоматически.

## Как залить на хостинг

1. Подключись по FTP (FileZilla, Total Commander или файловый менеджер в панели хостинга).
2. Зайди в папку сайта — обычно `public_html` или `www`.
3. Скопируй туда **всё содержимое** этой папки: `index.html`, `styles.css`, `app.js`, `data.js`,
   `favicon.svg` и папку `fonts` целиком.
4. Открой домен в браузере. Если страница старая — обнови жёстко: `Ctrl + F5`.

Дальше, чтобы обновить подборку, достаточно заливать один `data.js`.

## Ссылки на категории

Каталог сам подставляет параметры в адрес — можно давать прямую ссылку на нужный раздел:

- `сайт.ру/?cat=credit` — сразу кредиты наличными
- `сайт.ру/?cat=debit` — дебетовые карты
- `сайт.ру/?cat=mfo` — микрозаймы
- `сайт.ру/?q=альфа` — сразу с поиском по слову

## Что заложено внутри

- Живой поиск, фильтр по категориям и четыре сортировки — без перезагрузки страницы.
- Карточка продукта с условиями, порядком оформления и оговорками.
- Полная адаптация под телефон.
- Доступность по WCAG 2.2 AA: управление с клавиатуры, поддержка скринридеров,
  проверенные контрасты, видимый фокус, корректные заголовки и живые области.
- Ноль внешних запросов: шрифты, иконки и скрипты свои. Ни счётчиков, ни сторонних CDN.
- Никаких форм сбора персональных данных: заявка оформляется только на сайте партнёра.
